# Python 콘솔 퀴즈 게임

## 1. 프로젝트 개요

- Python의 기본 문법과 객체지향 프로그래밍(OOP)을 활용하여 터미널에서 실행되는 퀴즈 게임을 개발한다.
- Git과 GitHub를 이용하여 기능별 변경 이력을 기록하고 브랜치 생성, 병합, Clone, Push, Pull을 통한 협업 과정을 학습한다.

## 2. 프로그램 주요 기능

1. 퀴즈 풀기
   - Python 관련 객관식 문제 출제
   - 4개의 선택지 중 정답 선택
   - 정답 판정 및 점수 계산

2. 문제 추가
   - 새로운 문제와 선택지 4개 입력
   - 정답 번호 지정
   - JSON 파일에 저장

3. 문제 목록
   - 등록된 퀴즈 문제 확인

4. 최고 점수 확인
   - 최고 점수 조회 및 갱신

5. 종료
   - 프로그램 정상 종료

## 3. 프로젝트 구조

- main.py : 프로그램 실행 및 게임 기능 구현
- state.json : 퀴즈 데이터와 최고 점수 저장
- README.md : 프로젝트 설명 및 개발 기록
- .gitignore : Git 추적 제외 파일 설정

## 4. 프로그램 실행 흐름

1. 사용자가 터미널에서 main.py 실행
2. state.json 파일에서 퀴즈와 최고 점수 불러오기
3. 파일이 없으면 기본 퀴즈 데이터 생성
4. 메인 메뉴 출력
5. 사용자가 메뉴 번호 선택
6. 선택한 기능 실행
   - 퀴즈 풀기: 문제 출제, 정답 판정, 점수 계산
   - 문제 추가: 새 문제 등록 및 저장
   - 문제 목록: 등록된 문제 확인
   - 최고 점수: 기록된 최고 점수 확인
   - 종료: 프로그램 종료
7. 변경된 데이터가 있으면 JSON 파일에 저장
8. 종료를 선택하지 않았다면 메인 메뉴로 이동

## 5. 클래스 설계

### 5-1. Quiz 클래스

역할: 퀴즈 문제 하나를 관리한다.

주요 속성:
- question: 문제 내용
- options: 선택지 4개
- answer: 정답 번호

주요 기능:
- 문제와 선택지 관리
- 정답 확인
- JSON 저장을 위한 데이터 변환

### 5-2. QuizGame 클래스

역할: 전체 퀴즈 게임을 관리한다.

주요 속성:
- quizzes: 전체 문제 목록
- high_score: 최고 점수
- file_path: JSON 파일 경로

주요 기능:
- 메인 메뉴 실행
- 퀴즈 출제 및 점수 계산
- 새로운 문제 추가
- 문제 목록 출력
- 최고 점수 확인 및 갱신
- JSON 파일 저장 및 불러오기
- 잘못된 입력과 예외 처리

## 6. Git 및 GitHub 활용 계획

### 6-1. 버전 관리

- GitHub에 프로젝트 저장소 생성
- Git을 이용하여 변경 이력 관리
- 기능별로 최소 10회 이상 Commit
- Commit 후 GitHub에 Push

### 6-2. 브랜치 활용

- main: 기본 프로젝트 및 최종 완성본 관리
- feature/quiz-play: 퀴즈 기능 개발
- 기능 개발 완료 후 main 브랜치에 Merge

### 6-3. 협업 과정 실습

1. GitHub 저장소 Clone
2. 복제한 폴더에서 파일 수정
3. 수정 내용을 Commit 및 Push
4. 원래 프로젝트 폴더에서 Pull
5. 변경사항 동기화 확인

### 6-4. 개발 기록

- 기능별 변경사항을 Commit 메시지로 기록
- README에 프로그램 구조와 사용법 작성
- 주요 기능 테스트 결과 기록
